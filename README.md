# Chrona Android

Native Android shell around the Chrona premium calendar prototype.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync/download the Android Gradle Plugin.
3. Select the `app` configuration.
4. Build > Build APK(s).
5. Install the generated APK on an Android phone.

The app currently bundles the working Chrona HTML prototype inside a native Android WebView. It works offline for the bundled UI.
